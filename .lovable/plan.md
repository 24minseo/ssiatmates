# 할 일 추가 창 디자인 반영

## 구현 내용
- 첨부 이미지의 비율을 기준으로 할 일 추가 창을 넓고 세로로 긴 흰색 컨테이너로 조정합니다.
- 제목과 닫기 버튼을 같은 상단 행에 배치하고, 닫기 버튼을 우측 안쪽 여백에 맞춘 24px 영역으로 정리합니다.
- 지원사업 선택, 제목, 날짜·시작 시간 2열, 알림, 상세 내용 순서로 입력 구성을 맞춥니다.
- 취소·저장하기 버튼을 창 우측 하단에 고정된 형태로 배치합니다.
- 기존 일정 추가·수정 동작은 유지하고 `/calendar` 외 화면과 공통 앱 구조는 수정하지 않습니다.

## 기술 세부사항
- 캘린더 화면에서만 공통 대화상자의 기본 닫기 버튼 스타일을 덮어씁니다.
- 새 입력 상태는 기존 로컬 일정 데이터에 필요한 최소 범위로 추가하고, 기존 날짜·제목 유효성은 유지합니다.
- 기존 의미 기반 색상 토큰과 공통 입력·버튼 요소를 재사용합니다.

## 확인
- 할 일 추가 버튼과 날짜 칸에서 창을 열어 배치와 닫기 동작을 확인합니다.
- 추가·수정·취소·저장이 기존처럼 동작하는지 확인합니다.
- 데스크톱 화면에서 첨부 이미지와 크기·간격을 비교하고 빌드와 린트를 실행합니다.
