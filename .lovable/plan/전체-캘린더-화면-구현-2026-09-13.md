# 전체 캘린더 화면 구현

## 구현 내용
- `/calendar`에 2026년 8월로 시작하는 월간 캘린더를 구현합니다.
- 제목, 오늘/이전 달/다음 달 이동, 현재 월 표시, 월별·공고별 보기 전환을 구성합니다.
- 월별 보기는 일요일부터 토요일까지 7열로 고정하고, 월에 따라 5주 또는 6주를 자동 계산합니다.
- 이전·다음 달 날짜는 비활성 색상으로 표시하고 일정 영역은 비워 둡니다.
- 날짜 선택, 오늘 강조, 날짜 hover 시 `일지 쓰기`, 일정 선택 상세 보기를 구현합니다.
- `할 일 추가`에서 제목·날짜·내용을 입력해 로컬 상태에 저장하거나 취소할 수 있게 합니다. 선택된 날짜가 있으면 기본 날짜로 사용합니다.
- 공고별 보기에서는 등록된 일정을 날짜 기준으로 묶어 표시합니다.

## 화면 규칙
- 기존 1208px 콘텐츠 캔버스와 최소 1264px 본문 구조를 그대로 사용하며, 캘린더는 고정 7열을 유지합니다.
- 기존 의미 기반 색상 토큰과 공통 버튼·대화상자·입력 요소를 재사용합니다.
- 필요한 경우 비활성 날짜용 `content-disabled` 토큰만 전역 스타일에 추가합니다.
- 사이드바, 헤더, 앱 구조, 다른 화면은 수정하지 않습니다.

## 확인
- 월·연도 경계 이동, 오늘 이동, 선택/hover 상태, 일정 추가·취소·상세 보기, 두 보기 전환을 확인합니다.
- 빌드와 린트를 실행하고 실제 화면을 데스크톱 크기로 점검합니다.
