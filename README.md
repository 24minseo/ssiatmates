# ssiat

예비창업자와 창업자를 위한 맞춤형 지원사업 탐색 서비스

## Overview

지원사업 공고는 많지만 공고마다 지원 대상, 지역, 창업단계, 제출 서류와 신청 방법이 달라 자신에게 맞는 공고를 찾기 어렵습니다.

**ssiat**은 사용자의 상황과 관심 조건을 바탕으로 신청 가능한 지원사업을 쉽게 찾을 수 있도록 돕는 서비스입니다.

사용자는 창업단계, 신분, 거주지역, 사업장 소재지, 사업 분야와 관심 지원 분야를 입력할 수 있습니다. ssiat은 입력된 정보를 바탕으로 사용자의 조건에 맞는 지원사업을 우선적으로 보여줍니다.

또한 사용자가 자연어로 원하는 조건을 입력하면, 검색 내용을 구조화된 조건으로 변환하여 관련 공고를 탐색할 수 있습니다.

예를 들어 다음과 같이 검색할 수 있습니다.

> 사업계획서 없이 개인으로 신청할 수 있는 서울 지역 창업 지원사업을 찾아줘.

ssiat은 공고 원문을 단순히 나열하지 않습니다. 공고의 지원 조건을 검색 가능한 데이터로 정리한 뒤 사용자의 조건과 비교하여 실제로 관련성이 높은 공고를 찾습니다.

## Core Flow

```text
사용자 회원가입
→ 온보딩 정보 입력
→ 지원사업 조건 검색
→ 조건에 맞는 공고 필터링
→ 맞춤 공고 확인
```

## Key Features

### 사용자 인증

- 이메일 회원가입 및 로그인
- Google 로그인
- 로그인 세션 유지
- 로그아웃
- 사용자 프로필 관리

### 맞춤형 온보딩

- 창업단계 입력
- 신분 선택
- 거주지역 및 사업장 소재지 선택
- 사업 분야 및 관심 지원 분야 입력
- 온보딩 완료 상태 관리

### 지원사업 탐색

- 사용자 조건에 맞는 공고 필터링
- 지역·창업단계·신분·사업 분야 기반 검색
- 신청 조건에 따른 공고 비교
- 신청 기간이 유효한 공고 확인

### 자연어 검색

사용자의 자연어 요청을 검색 조건으로 변환합니다.

```text
사용자 요청
→ 검색 조건 구조화
→ 공고 조건과 비교
→ 관련 공고 반환
```

예를 들어 사용자의 요청은 다음과 같은 검색 조건으로 변환될 수 있습니다.

```json
{
  "business_plan_required": false,
  "individual_applicable": true
}
```

조건이 명확하지 않은 경우에는 임의로 검색하지 않고, 사용자가 원하는 조건을 구체적으로 선택하거나 입력할 수 있도록 안내합니다.

### 공고 정렬

검색 결과는 다음 기준으로 확인할 수 있습니다.

- 맞춤순
- 마감일 임박순
- 최신 등록순

맞춤순은 사용자의 조건에 맞는 공고를 우선 표시하고, 같은 조건의 공고는 마감일과 등록일을 기준으로 정렬합니다.

## Data Matching

ssiat은 공고와 사용자 요청을 각각 구조화하여 비교합니다.

### 공고 조건

공고 원문에서 다음과 같은 조건을 추출하여 저장합니다.

- 지원 대상
- 지역
- 창업단계
- 사업 분야
- 사업계획서 제출 필요 여부
- 개인사업자 신청 가능 여부
- 신청 방법
- 신청 기간

### 사용자 검색 조건

사용자의 자연어 요청은 공고와 비교할 수 있는 동일한 형식의 검색 조건으로 변환됩니다.

```text
공고 원문
→ 공고 검색 프로필

사용자 자연어
→ 사용자 검색 조건

두 조건 비교
→ 조건에 맞는 공고 반환
```

이때 LLM은 자연어를 조건값으로 변환하는 역할을 담당하고, 실제 조건 비교와 결과 조회는 데이터베이스에서 처리합니다. 이를 통해 검색 결과를 일관되게 유지하고, 조건에 맞지 않는 공고를 제외할 수 있습니다.

## Tech Stack

- Frontend: React, TypeScript
- Styling: Tailwind CSS
- Backend: Supabase
- Authentication: Supabase Auth
- Database: PostgreSQL
- Deployment: Lovable

## Project Goal

ssiat은 지원사업 정보를 찾는 데 필요한 시간과 노력을 줄이고, 사용자가 자신의 상황에 맞는 공고를 놓치지 않도록 돕는 것을 목표로 합니다.

많은 공고를 직접 비교해야 하는 부담을 줄이고, 복잡한 지원 조건을 이해하기 쉬운 방식으로 제공하는 맞춤형 지원사업 탐색 서비스를 만들어가고 있습니다.
