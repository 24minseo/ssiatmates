# ssiat

예비창업자와 창업자를 위한 지원사업 탐색 서비스

## 프로젝트 소개

ssiat은 예비창업자와 창업자가 자신에게 필요한 지원사업을 쉽고 편하게 찾아볼 수 있도록 돕는 서비스입니다.

지원사업 공고는 종류가 많고, 공고마다 지원 대상·지역·창업단계·신청 기간 등의 조건이 달라 원하는 정보를 직접 찾기 어렵습니다. ssiat은 이러한 정보를 한곳에서 확인하고, 사용자의 상황에 맞는 지원사업을 탐색할 수 있도록 서비스를 제공합니다.

사용자는 회원가입 후 기본 정보를 입력하고, 지원사업 공고를 확인하거나 관심 있는 사업을 저장할 수 있습니다. 공고 목록은 맞춤순, 마감일 임박순, 최신 등록순으로 정렬하여 원하는 기준에 따라 확인할 수 있습니다.

## 주요 기능

### 회원가입 및 로그인

- 이메일 회원가입 및 로그인
- Google 로그인
- 로그인 상태 유지
- 로그아웃
- 사용자 계정 정보 확인

### 맞춤형 온보딩

- 생년월일 입력
- 신분 선택
- 창업단계 선택
- 거주지역 선택
- 사업장 소재지 선택
- 사업 분야 선택
- 관심 지원 분야 선택

### 지원사업 탐색

- 지원사업 공고 목록 확인
- 공고 상세 내용 확인
- 맞춤순 정렬
- 마감일 임박순 정렬
- 최신 등록순 정렬
- 관심 지원사업 저장

### 내 지원사업 관리

- 저장한 지원사업 확인
- 지원사업 상태 관리
- 지원 일정 기록
- 지원사업별 진행 상황 확인

## 서비스 이용 흐름

```text
회원가입 및 로그인
→ 기본 정보 입력
→ 지원사업 탐색
→ 관심 공고 저장
→ 지원 일정 및 진행 상황 관리
```

## 기술 스택

- Frontend: React, TypeScript
- Styling: Tailwind CSS
- Backend: Supabase
- Authentication: Supabase Auth
- Database: PostgreSQL
- Deployment: Vercel
- Development: OpenAI Codex
